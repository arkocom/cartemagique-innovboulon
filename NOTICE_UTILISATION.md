# 📋 CarteMagique - Notice d'Utilisation

## 🎄 Bienvenue dans CarteMagique !

CarteMagique est une application simple et intuitive pour créer des cartes de vœux personnalisées en quelques clics. Parfait pour souhaiter une bonne fin d'année à vos proches !

---

## 🚀 Guide Rapide

### Étape 1 : Choisir un fond
1. Sélectionnez une catégorie (Noël, Nouvel An, Hiver)
2. Choisissez parmi 30 modèles festifs
3. Cliquez sur **"Personnaliser ma carte"**

### Étape 2 : Personnaliser votre carte
- **Ajouter du texte** : Cliquez sur "Ajouter" pour ajouter un bloc de texte
- **Modifier le texte** : Sélectionnez un bloc et tapez votre message
- **Changer la couleur** : Choisissez parmi 4 couleurs principales (Blanc, Noir, Rouge, Or)
- **Changer le style** : Classique, Moderne, Élégant ou Festif
- **Ajuster la taille** : Utilisez le slider pour augmenter ou diminuer la taille du texte
- **Déplacer les éléments** : Cliquez et glissez sur la carte pour repositionner

### Étape 3 : Ajouter des images
1. Cliquez sur **"Ajouter une image"**
2. Sélectionnez une photo depuis votre appareil
3. Déplacez et redimensionnez-la sur la carte
4. Utilisez le slider pour ajuster la taille

### Étape 4 : Ajouter un cadre blanc
1. Cochez **"Ajouter un cadre blanc"**
2. Ajustez l'épaisseur avec le slider (0-40px)
3. Parfait pour un effet photo polaroid !

### Étape 5 : Exporter votre carte
1. Cliquez sur **"Partager ma carte"**
2. Choisissez :
   - 📱 **Partager / Télécharger** : Envoyez directement par WhatsApp, email, etc.
   - 💾 **Télécharger uniquement** : Téléchargez le fichier PNG
   - ✏️ **Modifier** : Continuez à éditer

## 📸 Conseils pour les Images

### Format Recommandé
- **Format idéal** : Carré (1:1) - 500×500px ou plus
- **Exemples** : Logos, photos de profil, icônes
- **Formats acceptés** : JPG, PNG, WebP

### Bonnes Pratiques
✅ **À faire :**
- Utiliser des images de bonne qualité (au moins 300px)
- Préférer les images avec fond transparent pour les logos
- Tester différentes positions sur la carte
- Utiliser des images carrées pour un meilleur rendu

❌ **À éviter :**
- Images trop petites (< 200px)
- Images très compressées ou floues
- Trop d'images sur une seule carte (max 3-4)
- Images avec beaucoup de texte (difficile à lire)

## 🎨 Conseils de Design

### Combinaisons de Couleurs Recommandées
- **Classique** : Blanc + Noir + Or
- **Festif** : Blanc + Rouge + Or
- **Moderne** : Noir + Or
- **Élégant** : Blanc + Or

### Styles de Texte
- **Classique** : Parfait pour les messages formels
- **Moderne** : Idéal pour un look contemporain
- **Élégant** : Excellent pour un rendu premium
- **Festif** : Amusant et coloré

### Positionnement
- Centrez le texte principal au milieu de la carte
- Placez les images dans les coins ou en arrière-plan
- Laissez de l'espace blanc pour une meilleure lisibilité

## 💡 Astuces Pratiques

1. **Prévisualisation** : Avant de partager, vérifiez votre carte dans le modal de prévisualisation
2. **Cadre blanc** : Augmentez l'épaisseur pour un effet plus prononcé
3. **Multiples textes** : Créez plusieurs blocs pour un design plus complexe
4. **Partage social** : Utilisez "Partager" pour envoyer directement via WhatsApp ou email
5. **Historique** : Votre dernière création est sauvegardée automatiquement

## ❓ Questions Fréquentes

**Q : Puis-je modifier ma carte après l'avoir créée ?**
A : Oui ! Cliquez sur "Modifier" dans le modal de prévisualisation.

**Q : Quel est le format de sortie ?**
A : PNG haute qualité (400×600px) avec cadre blanc optionnel.

**Q : Puis-je utiliser mes propres images ?**
A : Oui, cliquez sur "Ajouter une image" et sélectionnez un fichier depuis votre appareil.

**Q : Comment puis-je partager ma carte ?**
A : Cliquez sur "Partager ma carte" et choisissez votre méthode (WhatsApp, email, etc.).

**Q : Y a-t-il une limite au nombre de cartes ?**
A : Non ! Créez autant de cartes que vous le souhaitez.
